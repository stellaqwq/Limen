# 抖音网页浏览

“抖音网页浏览”内置插件使用本机 Chrome 的独立可见窗口，让支持图片输入与工具调用的模型观察视频画面、播放/暂停和切换下一条。无需安卓模拟器。网页登录仍可能要求登录或验证；插件不会解决、绕过验证码或改变浏览器指纹。

## 使用

1. 启动新版工作台，在“插件 → 插件概览 → 抖音网页浏览”安装插件。首次手动安装默认停用，再次打开保留已有配置。
2. Chrome 路径可留空，程序查找本机安装。默认每任务最多 5 条、180 秒。保存后启用；默认供已认证的网页测试对话使用；可另开“允许 QQ 管理员私聊观看”，并把管理员 QQ 填入插件好友范围，同时遵守 AI 白名单。
3. 在“Agent 管理 → 抖音网页浏览”点击“打开抖音网页”。在这个专用 Chrome 窗口中手动完成登录或处理弹窗、验证码。
4. 打开“测试对话”，例如发送：“观看抖音网页，最多 5 条，每条采样画面并总结，只观看和切换。”
5. “查看网页画面”可手动获取快照；“停止网页操作”取消任务的后续控制。停止状态在重启后保留，恢复后需要发起新任务。

五条视频通常需要超过默认 8 次模型请求。在执行设置中将模型请求上限设为 16；如果同时频繁播放/暂停，也可能需要增加工具调用上限。任务条数、时长上限仍由插件独立约束。

不指定数量时，“去刷视频”会进入后台持续浏览，直到说“停止刷视频”；“去刷一会儿视频”允许模型自主结束。两种模式每轮只处理当前一条，可以继续采样或划走，不要求开启自动分享。条数上限约束指定数量的任务，时间与模型调用上限继续约束每轮。管理页显示持续会话状态，停止、失败、修改配置或退出会结束会话，重启不自动续刷。详见[持续浏览和自主结束](DOUYIN-AUTONOMY.md#持续浏览和自主结束)。

## 三个工具

| 工具 | 行为 |
| --- | --- |
| `douyin_web_status` | 读取浏览器、页面、播放器、登录/验证阻挡和当前任务预算，不启动窗口。 |
| `douyin_web_observe` | 返回 1–8 幅真实 JPEG 采样画面、时间、播放器秒数、页面文字摘录和观察编号。 |
| `douyin_web_action` | 仅允许打开固定抖音推荐页、播放、暂停或切换下一条。 |

截图没有音频输入，不等于听过配乐或对白；本地文件的视频转写插件不会自动录制浏览器声音。页面 DOM 摘录可能包含预载的相邻视频文案，描述当前内容应以截图为准。截图只送入当前模型请求，不进入持久化工具回执；诊断命令会显式在本机保存快照。

需要对白时，可另开[抖音视频对白转写](DOUYIN-AUDIO.md)：由抖音插件采集当前可见视频的短音轨，再复用视频插件已配置的 ASR。模型收到的是带采样来源的机器转写；原始录音不长期保留。未开启、采集受限或转写失败时，仍只依据画面理解。

持续/自主浏览把同批多帧按时间顺序合成一张带 Frame 编号的图，模型输入最多960×1280，减少多图视觉处理开销；采样数量、间隔、原始画面证据和哈希保持不变。格子按从左到右、从上到下排列，代表不同采样时刻。小字和细节可能缩小，模型不应猜测无法辨认的内容。单帧与手动预览仍直接使用原图。

“画面采样”可配置每批最低画面数 `min_observe_frames` 和最短采样间隔 `min_observe_interval_seconds`。当前工作区设为6幅、3秒，即通常跨约15秒；模型传入更小的值时仍按管理员下限采样。新配置缺省保留旧行为，手动预览固定1幅。单批最多8幅、间隔最多10秒，模型采样图片限制在960×720范围内，并沿用合计6,000,000字符的图片预算。返回实际采样跨度及提前结束原因；临近视频结尾会缩短采样，期间切换视频时标记为混合来源，不能据此入库或自动分享。

`observe_after_action: true` 只表示动作后需要再观察页面。实际登录或验证阻挡由 `blocked: login_required / verification_required` 表示，不应把“需要再观察”理解为验证码。

## 浏览器与控制范围

- 使用 Chrome DevTools 本地管道通信，不开放调试 TCP 端口，不连接日常浏览器。专用浏览器资料保存在当前数据目录的 `douyin-browser-profile`，重启保留其登录状态。
- 只控制本插件创建的标签页，并检查精确的 `https://www.douyin.com` 来源。用户把标签页切到其他站点后，工具拒绝读取及控制；关闭专用窗口后可以重新打开。
- 浏览器管道支持的脚本和导航由程序固定，模型没有任意 URL、JavaScript、选择器、点击、输入或 Cookie 读取接口。不会点赞、评论、关注或安装扩展。
- 首条计入条数；默认最多四次“下一条”。动作后必须重新观察，再引用最近 30 秒、同一任务和同一页面的观察编号。前台视频缺失、页面变化、登录/验证、其他任务占用、到达条数/时间上限时拒绝动作。
- 每个动作使用 `operation_id` 持久回执。模型失败或任务恢复后，执行过浏览器动作的旧任务不会自动重放。停止可取消待完成的调用，但已送达页面的动作可能生效。停止不会自动关闭浏览器或保证暂停已经播放的视频。
- 内置页面检测可识别已知登录及风险提示，但不能保证覆盖所有站点改版或弹窗；模型还需观察截图并在异常时停止。插件不保证网站永远不触发风控。
- 工作台退出或重启时关闭专用窗口，下一次打开复用专用资料。Chrome 的窗口与登录状态独立于原有安卓插件。

## 从 QQ 私聊调用

在“抖音网页浏览”的插件编辑页开启 `qq_private_enabled`（允许 QQ 管理员私聊观看），在上方“好友 QQ 号”填入调用者，并确认此人同时属于 `BOT_ADMIN_IDS` 和 AI 回复范围。保存后，在机器人 QQ 私聊中发送：“去抖音看3条视频，每条采样画面并总结，只观看和切换。”

QQ 私聊使用同一个专用 Chrome，仍受条数、时间、真实采样、操作去重和紧急停止约束。可以调用 `douyin_web_status`、`douyin_web_observe`、`douyin_web_action`，知识库开启时还可检索和保存观看笔记。当前项目已为配置的 QQ 管理员启用此入口。

普通用户、群聊及插件范围以外的账号无法取得这些工具。普通抖音私信、聊天读取和分享草稿保持网页管理入口；另可开启[自主刷视频与分享](DOUYIN-AUTONOMY.md)，向 QQ 明确刷视频任务提供固定默认好友的推荐组合工具。QQ 与网页任务互斥占用浏览器。无未发送文字的消息/分享面板可通过 `close_social` 关闭后继续观看。

只问“你能刷抖音吗”时，模型依据当前工具说明回答能力；明确要求观看后才开始操作。历史对话中的能力否认不改变当前权限。未在真实 QQ 主动发送验收消息，QQ 队列链路在隔离模拟驱动中验证。

## 命令行

```powershell
npm run douyin:web -- configure
# 完整重启新版工作台后：
npm run douyin:web -- status
npm run douyin:web -- open
npm run douyin:web -- observe
npm run douyin:web -- stop
npm run douyin:web -- resume
npm run douyin:web -- trial
```

`configure` 为当前数据目录暂存一次性配置，下次完整启动安装并启用新插件，同时停用安卓浏览入口，保留原设备配置。其他数据目录的测试实例不会误消费配置。已有网页插件保留启用状态。

`observe` 在 `runtime/douyin-web/page.jpg` 保存本机截图。`trial` 会使用正式工作台的当前模型真实执行网页任务，默认最多五条；可用 `trial 4` 验收最多四条。结果在 `runtime/douyin-web/trial-result.json`。登录或验证阻挡时会报告并停止，需要用户处理后创建新任务。

## 实现与验证

浏览器执行层使用 Chrome 自带的 DevTools 协议和独立资料目录，不需要额外下载 Playwright 浏览器或安卓系统。协议参考：[Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/)。

本机已验证真实 Chrome 启动、推荐页加载、登录弹窗识别、JPEG 截图及网页模型任务。用户处理登录弹窗后，模型成功采样并切换视频；发现返回标记可能被模型误读为验证码后，已改用明确的 `observe_after_action`。修正后完成四批画面采样和三次切换尝试，观察到三条不同视频，其中一次切换未生效被模型通过后续截图识别；未把动作回执当作换片成功的证明。这轮未出现实际登录或验证阻挡。日常上限已恢复为五条。单元与集成回归覆盖来源限制、登录/验证码停止、条数预算、重复动作、防恢复重放、管理接口认证和停止取消；完整回归 514 项通过，修正文案后的定向检查通过。管理页已检查桌面和手机宽度。

真实播放控制补充验收：模型在同一条视频执行暂停 → 观察确认 paused=true → 播放 → 观察确认 paused=false → 再暂停 → 观察确认 paused=true，全程没有切换视频或触发登录/验证，最终将视频留在暂停状态。回执与步骤记录见本机 runtime/douyin-web/playback-check.json。

## 视频学习

开启“视频学习 → 视频知识库”后，可另启用自动归档和回答前召回。原三个浏览器工具保持原职责，新增 video_knowledge_save 和 video_knowledge_search 两个笔记工具；它们仍只供管理员网页对话使用。详见 [视频知识库](VIDEO-KNOWLEDGE.md)。

## 好友分享与私信

可开启“分享与私信”草稿功能，由模型读取联系人并生成待发草稿，在 Agent 管理页准备、核对和确认发送；普通草稿不提供模型发送工具。独立的“自主刷视频”设置允许明确刷视频任务自动分享和私信给默认好友。详见 [抖音分享与私信](DOUYIN-SOCIAL.md)及[自主刷视频](DOUYIN-AUTONOMY.md)。

QQ 入口验收：551项全量回归通过；3项 QQ 定向测试覆盖管理员/好友范围与群聊隔离、能力询问不启动操作、QQ 队列中实际采样图片和切换工具循环。当前配置的管理员已加入插件好友范围并启用入口，原默认好友及自动聊天设置保留。

当前真实配置模型的独立能力检查也已通过：提供与 QQ 私聊相同的浏览工具和权限说明后，模型回答“能刷，只能看、暂停、下一条，遇到登录验证就停。”检查未触发实际浏览或发送 QQ 消息。报告：runtime/douyin-web/qq-capability-model-check.json。
