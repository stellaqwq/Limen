# 插件管理界面验证

日期：2026-10-27。范围为现有本机管理台中的插件功能扩展，沿用既有设计系统。

## 继承的样式

已对照 `DESIGN.md`、`.impeccable/design.json`、`src/web/styles.mjs` 与新增 `src/web/plugins.mjs`。新增界面使用现有松绿侧栏、灰白背景、白色面板及细边框；文字使用现有中文系统字体，代码与 JSON 使用 `--mono`。面板、按钮、状态标签、焦点和错误提示沿用现有样式，未增加全局设计 token，也未修改原有设计文件。

插件列表以状态、范围、优先级和运行统计支持日常管理；编辑器使用明确标签区分元数据、范围、代码和配置。1100px 以下代码区和列表操作改为单列；680px 以下表单和模拟字段单列。超长代码在文本域内滚动，不撑宽页面。

- `dist/test-results.json`：247 项测试全部通过，包括插件管理接口、凭据隔离、输入校验、版本冲突、启停、执行顺序、去重、会话筛选、超时、故障、重启持久化和进程中断后的防重。

- `.impeccable/review/plugins/report.json`：插件管理操作检查通过，包括新建、JSON 校验、保存、启用、模拟消息回复、预览转义、超时、冲突保留草稿、导入默认停用、删除和搜索；无 JavaScript 或 CSP 错误。超时和版本冲突的两个 HTTP 错误为预期结果。
- 检查宽度：1440、1024、768、680、390 和 320px；无页面横向溢出。截图包括桌面、手机、320px、空列表、冲突、列表和手机校验状态，位于 `.impeccable/review/plugins/`。

## 独立审查的修正

初次审查提出两项实质问题：编辑器错误提示离保存操作过远；草稿修改后文案错误地暗示停用插件会生效。已在保存区增加可聚焦错误提示，并分别保留“保存后默认停用”“保存后仍停用”和“保存后即时更新”的状态文字。手机端浏览器断言确认错误提示可见且获得焦点。复核将这两项均评为已解决；`ship` 结论仅覆盖这两项修正。

## 验证限制

所有业务操作使用模拟 QQ 数据，尚未使用真实 QQ 账号验收插件回复。独立审查通过源码、报告与截图复核，没有独立驱动浏览器。impeccable 引擎未安装且缓存不可写，使用了直接读取现有设计上下文的降级路径，未运行自动设计检测器。未修复与本次扩展无关的既有设计差异。

文档复核发现既有 `.impeccable/design.json` 的移动流程示例仍为横向排列，侧栏焦点示例仍使用深绿；当前全局样式已使用移动端纵向步骤和浅色侧栏焦点。此处记录已有差异，保留原文件，未在插件扩展中改写全局设计记录。
