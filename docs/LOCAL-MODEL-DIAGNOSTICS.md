# 本地模型请求诊断

Chat Plus 可能为一次群聊发起多个用途不同的模型请求：普通消息先读空气，图片可在后台单独描述，决定参与后才生成正式回复。因此 LM Studio 后台出现请求，不代表已经进入正式回复阶段。

## 2026-10-28 排查记录

只读检查用户本机任务记录与 LM Studio 服务日志，发现多个读空气请求用完了固定的 512 Token，任务未取得判断正文；同时存在客户端断开并取消生成的记录。后台图片描述默认有 20 秒独立超时，读空气也有独立超时，排队、模型加载、提示词处理和生成都占用这个时间预算。

此前辅助调用省略 `reasoning_effort`。省略不等于关闭思考；[Qwen3.5 官方模型说明](https://huggingface.co/Qwen/Qwen3.5-9B)说明该模型默认思考。当前本机 LM Studio 模型能力接口也报告默认 on，支持 off / on。开启思考且只有 512 个输出 Token 时，可能把额度花在思考内容上，而没有最终 JSON。

修复后，辅助请求默认显式发送 `reasoning_effort=none`，主回复保留用户的 `high`。使用固定测试输入实测：流式请求约 581ms 完成，返回 6 个输出 Token、0 个思考 Token，停止原因为 stop。测试没有使用群消息或发送 QQ 回复；具体延迟受排队和机器负载影响。

## 对应设置

“群聊增强 → 全局配置 → AI 读空气”：

- **判断模型推理强度**：默认 none；不支持该参数的服务可留空，使用模型服务默认。
- **判断生成 Token 上限**：默认 512；包含思考与最终判断 JSON。使用必须思考的模型时需要更多额度。
- **判断超时**：包含排队和模型加载时间，冷启动或同一模型处理多个请求时可适当增大。

“图片描述”分组同样有独立推理强度和 Token 上限，默认 none / 2048。只希望提问图片时识图，可关闭“后台描述未 @的图片”，保留“启用图片描述”。

## 看哪些信息

在“运行监控 → 任务队列 → 查看消息与回复”查看：

- **仅有思考内容，没有判断正文**：模型产生了思考，但没有最终判断。
- **停止原因 length**：达到输出 Token 上限，判断 JSON 可能尚未产生或被截断。
- **请求超时**：时间预算包含排队、加载、输入处理和输出，不仅是生成阶段。
- **响应中断 / 模型流式响应报错**：服务没有正常完成本次返回。
- **服务状态码**：用于区分参数不兼容、鉴权、限流和服务故障。
- **Token 统计**：输入、总输出及其中的思考 Token；服务没有返回统计时不会填 0 冒充真实值。

“运行日志”可区分读空气请求失败、输出无效、判断完成及图片描述失败。日志只记录结构化诊断，不记录提示词、模型理由、思考正文或服务错误原文。

提示词处理百分比由 LM Studio 自身显示；没有百分比不能单独证明模型未执行，应结合服务的 Token 统计、任务停止原因及取消记录判断。[LM Studio 日志工具](https://lmstudio.ai/docs/cli/serve/log-stream)可用于进一步核对服务执行情况。

本次修改需要重启机器人项目加载。既有失败任务只有此前保存的信息，新增诊断从新请求开始完整记录。
