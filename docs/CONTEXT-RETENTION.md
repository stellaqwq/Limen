# 完整上下文保留

默认 `AI_CONTEXT_TURNS=-1`，不限制会话轮数；`HISTORY_RETENTION_DAYS=0`，不按天删除任务、会话历史、显式记忆或 OneBot 消息查询缓存。已有配置需要同步改为这两个值并重启。0 轮仍表示不提供历史，正数仍可用于主动限制最近轮数。

每次模型请求保存实际发送的系统提示词、对话、工具定义和生成参数；保存完整 JSON 响应或 SSE 数据帧，包括接口返回的 `reasoning_content`、`reasoning`、结构化思考及工具调用。认证请求头不进入档案。中断请求已收到的 SSE 数据帧继续保留。

成功完成的会话历史保留本轮实际输入、模型完整正文、返回的思考、工具调用及结果，后续请求继续携带。QQ 最终发送的正文仍遵循原来的输出长度和内容过滤设置，保存的模型原文不因此截短。图片和文档使用实际提交给模型的内容；应用读取文件时原有的采样和提取限制仍生效。

所有数据位于 `DATA_DIR/bot.sqlite`：`history.messages` 保存可接续的完整消息，兼容旧版纯文本历史；`model_requests` 和 `model_response_frames` 保存请求响应档案；`model_turn_drafts` 保存当前生成的过程。数据库迁移只增加表和列。

`/context` 显示不限制轮数及已保留消息数。`/new` 或管理台清空上下文仍能开始新对话，旧请求响应档案继续保留用于核对，不会自动重新进入新对话。群聊近期背景的独立 15 分钟窗口及长期记忆插件的衰减归档规则继续按各自配置工作。

模型服务本身仍有 token 窗口。超过服务窗口时会按现有错误流程报告失败，不自动截断或删除历史。只保存接口实际返回的思考，无法获取服务未返回的内部推理，也不能找回升级前已清理的数据。
