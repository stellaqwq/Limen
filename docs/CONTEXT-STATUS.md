# 管理员上下文查询

当前默认保留全部会话轮次与模型返回的思考，不按天清理历史。配置和数据表说明见[完整上下文保留](CONTEXT-RETENTION.md)。

在当前 QQ 会话发送 `/context`、`/ctx` 或 `/上下文`。仅 `BOT_ADMIN_IDS` 配置的聊天管理员可用，不依赖安装任何插件，AI 关闭时也能查看本地历史窗口。群聊查询当前群的共享上下文，私聊查询当前好友会话；查询不会清空历史或写入模型对话。

回复包含：

- `AI_CONTEXT_TURNS` 控制的历史窗口：已使用、可继续容纳的轮数和保留消息条数。默认 -1 不限制轮数；仅主动配置正数时滚动淘汰旧对话。
- 当前模型及模型接口 `/models` 返回的上下文窗口大小。元数据成功缓存 5 分钟，查询失败或不支持时明确显示不可计算。
- 最近一次当前会话模型请求实际返回的输入、输出 token。窗口剩余参考为模型窗口减去该次输入和输出 token，不是累计账单，也不是下一次请求的精确预测；包含该次请求中的系统提示词、工具等内容，下一次请求会重新组装历史与附加背景。

用量从更新后的正常模型请求开始记录，存入 `conversation_token_usage`，不记录提示词、回复正文或凭据。服务重启后仍保留；模型或接口改变后不复用旧模型用量。`/new` 清空会话时同步清除用量；人格和长期记忆沿用原有保留规则。

流式请求使用兼容 Chat Completions 的 `stream_options.include_usage` 获取统计；接口未返回统计时显示未知，不按字符数估算 token。

DeepSeek 的模型元数据字段参考[官方模型列表接口](https://api-docs.deepseek.com/api/list-models/)。查询只读取已经配置的模型接口，不发送新的模型生成请求。
