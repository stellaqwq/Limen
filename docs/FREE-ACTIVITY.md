# 自由活动插件

在“插件管理 → 内置插件”选择“自由活动”，填写管理员 QQ 私聊范围后启用。也可导入 `dist/free-activity.plugin.json`。网页 Agent 试聊在插件启用后可使用；QQ 还需符合 AI 白名单。群聊不启用自主执行。

在“插件管理 → 自由活动 → 编辑”中，下方“定时自由活动”区域可以新增、修改、启停和删除定时。支持间隔、每天北京时间和延后一次；选择符合管理员、AI 白名单和已保存插件范围的 QQ 会话，填写活动方向后点击“新增定时”或“保存定时”。定时单独保存，立即生效；聊天指令创建的定时也显示在同一列表。已有网页定时可在这里继续编辑，保持原网页会话。

保存插件兴趣、工具类别等配置和重载插件会保留已有定时。停用插件会停用对应定时，重新启用后可在编辑页逐个恢复。修改定时会停止其尚未完成的旧轮次并重新计时；已提交的操作不会撤销。多人同时编辑或聊天指令更改了定时时，会保留草稿并提示刷新。

示例（时间均为北京时间）：

```text
自由活动
自由活动：找点有意思的事情做，可以看看桌面再画一张画
定时 每隔30分钟 自由活动
定时 每天20:30 自由活动：整理今天的灵感
定时 10分钟后 自由活动
查看自由活动定时
取消自由活动定时 <编号>
取消自由活动定时 全部
停止自由活动
自由活动帮助
```

另支持 `/free now`、`/free schedule 每隔30分钟 自由活动`、`/free list`、`/free cancel <编号或all>`、`/free stop`。

每轮先用 `free_activity_plan` 保存候选清单和选择，默认最多选择两项，再执行所选事项需要的工具。模型复用现有 ComfyUI、抖音网页浏览、PowerShell、文件和桌面工具；各工具自身开关、会话范围、人格工具清单、文件目录范围和紧急停止仍然生效。插件配置可修改兴趣、允许工具类别、事项数、时限和定时数量。生图进入最终回复阶段，组合活动时先完成其他步骤再生图。

定时间隔最少一分钟；支持间隔、每天和延后一次。定时保存在原数据库，重启后继续；错过的时间合并为一轮，不追赶积压次数。QQ 离线或当前会话忙碌时等待；未知发送不会被新定时覆盖。插件、AI 或会话权限撤销、人格变更会停用对应定时。保持Limen运行才能执行。每轮会请求已配置的模型服务。

“停止自由活动”会立即中断本会话活动，同时取消本会话全部定时。取消某个定时也会取消它尚未开始的任务，或中断其正在执行的工具循环。已提交的桌面、命令或生图操作可能已生效，停止不撤销既有操作。

清单与执行状态分别保存在 `free_activity_runs`，定时保存在 `free_activity_schedules`。原任务列表可查看每轮生成、工具调用、实际结果及回复；定时控制指令也可直接在 QQ 中完成。活动不会因模型错误自动重放；恢复后中断的轮次保留记录。停用插件会停止活动；重新启用后，已停用的定时需重新设置。原始记录默认保留90天，插件导出不包含定时及活动记录。

本插件包含宿主集成代码，安装 JSON 前须先安装本次源码更新；不支持将其作为未更新旧宿主上的独立脚本使用。
