# 从视频建立记忆和知识库

抖音网页插件可以让模型在浏览任务里自主整理笔记，保存到项目的 SQLite 知识库，并在以后回答相关问题时检索。保存和检索不需要额外下载模型或部署向量数据库；目前复用本地中文双字词和 BM25 关键词检索。这是持久化笔记与检索，不会修改聊天模型的权重，也不会在后台无限刷视频。

## 开启

1. 在“插件 → 抖音网页浏览 → 视频学习”启用“视频知识库”。默认新安装关闭，管理员开启后允许模型自主保存本任务实际采样的视频内容，无需每条重新请示。
2. “观看后自动归档”开启时，模型在切下一条或结束前整理当前视频。有可学习的内容时保存知识笔记；没有可提炼的知识时只保存观看记忆。切下一条的工具会检查当前采样是否已归档。
3. “回答前自动检索”开启后，新网页会话也能召回相关视频笔记。知识库供当前管理员网页入口及已授权的 QQ 管理员私聊共享，独立于用户偏好记忆和“流动记忆”中的 QQ 用户事实。不会把视频观点自动写成用户事实。
4. 进入“Agent 管理 → 视频知识库”搜索、查看来源和采样位置、归档或恢复笔记。停止浏览器、关闭 Chrome 或重启服务不会清空笔记。关闭知识库开关会停止学习和自动检索，管理页仍可查看已有条目。

例如，在测试对话发送：

> 浏览抖音网页，最多 3 条，自主整理有用的内容到知识库。没有知识点时只保留观看记忆，不猜测声音。

以后在新会话询问：

> 之前看的视频里有哪些相关方法？请区分视频中的说法与已经核实的事实，并说明来源。

自动学习会增加保存笔记的工具调用次数，不额外启动后台模型。浏览五条视频时建议模型请求上限至少 20、工具调用上限至少 24；浏览条数和时长仍由插件限制。人格如限定工具清单，需要包含 `video_knowledge_save`；手动检索使用 `video_knowledge_search`。

## 保存什么

每条笔记包含标题、摘要、标签、类型（观看记忆或知识笔记），以及执行层填入的来源和证据：

- 本任务真实 `observation_id`，采样时间、播放器秒数、画面的 SHA-256 指纹和任务编号。
- 如果从当前视频容器或页面地址识别到视频 ID，保存规范的抖音视频链接；不能识别时明确标记为“推荐页快照，未定位原视频”，不编造精确来源。
- 固定的 `unverified_video` 状态：所有条目都是视频中的未核实说法或采样观察，不自动升级为可信事实。
- 手机截图和未开启对白转写的浏览器采样只有画面，不能猜对白、配乐或未采样部分。浏览器可开启[短音轨自动转写](DOUYIN-AUDIO.md)，真实转写随来源保存并参与检索；机器识别可能有误。页面 DOM 可能包含预载相邻视频，不能据此混入其他视频的内容。

笔记内容由模型概括，仍可能有识别错误；采样范围有限，不等于看完了整条视频。事实核验需另外查证，不能只因为已经存进知识库就认定正确。

## 存储和边界

`video_knowledge_save` 是有操作回执的写入工具，模型必须引用同一任务的实际采样。执行层填入来源、时间和证据，模型不能传入自己的来源地址或“已核实”标志。手动点击网页预览不会自动入库。登录、验证阻挡、无播放器、采样期间视频切换、其他任务的观察编号都不能保存。

同一来源和笔记类型会更新合并，保留最近八批采样的来源元数据。来源无法精确定位时，跨次重看的去重效果有限。默认最多 1,000 条有效笔记，达到上限后停止新增；可归档旧条目腾出有效笔记额度。归档条目不会在自动保存时悄悄恢复，只能由管理页主动恢复。全部条目（含归档）设有 10,000 条存储上限。

数据库只保存文本、来源和帧指纹，不保存截图本体。截图仍是临时模型输入；笔记不保存凭据。移除插件不自动清除已有知识库行；重装产生新的插件编号，不会自动挂接旧编号数据，需备份原数据库。

自动检索向管理员网页任务及已开启 QQ 浏览权限、处于插件好友范围和 AI 白名单内的管理员私聊注入少量相关笔记，标明它们是不可信的视频资料，不能改变系统权限。普通私聊和 QQ 群聊不会获得这些工具或自动注入。

## 验证

新增测试覆盖：开关默认关闭、同任务证据约束、伪造来源拒绝、登录/混合视频拒绝、自动归档前置检查、去重、归档恢复、凭据过滤、条数限制、关闭浏览器及重建服务后的检索、真实 Agent 提示词中的来源标注、管理接口认证和版本冲突。

浏览器验收覆盖设置开关、来源展示、搜索、归档和恢复，以及桌面和移动宽度。管理页测试使用明确标为“演示”的笔记；真实模型学习验收另存于本机 `runtime/douyin-web/knowledge-learning-check.json`。

本机真实模型验收：当前项目已开启自动归档和自动召回。模型对《我的世界》实况采样后自主调用入库工具，判断没有可提炼知识而保存 watch_note；来源未定位到精确视频时保留 feed_snapshot 标记，不编造视频链接。验收结束暂停视频。523 项全量 JavaScript 测试和新增管理页、原 Agent 页面回归通过。

跨会话真实召回也已通过：新建一个无观看历史的网页会话，模型通过 video_knowledge_search 找回上述观看记录，明确回答采样范围和 video_id 未定位的限制；没有打开浏览器或新增笔记。结果保存于 runtime/douyin-web/knowledge-recall-check.json。
