# Web 管理端重做与验收

用户确认的重点：主要管理机器人，直接 Agent 对话默认隐藏，通过切换打开。

## 页面变化

- 默认首页为机器人运行概览，突出账号连接、AI 回复状态、任务核对和管理快捷入口。
- 浅灰侧栏、白色内容面、深灰文字与蓝紫色操作强调替换原有深绿色界面。导航按机器人管理、内容与运行、配置分组。
- Agent 管理拆为会话与记忆、人格配置、工具与执行三个页签，避免长页面堆叠。
- 顶部“测试对话”提供可切换的测试界面，默认隐藏，可返回原管理页面。新增 Enter 发送、Shift+Enter 换行，保留输入法组合状态。
- 统一表单、表格、状态、确认、空状态、焦点和窄屏布局。手机主要点击区域至少 44px；概览刷新按钮保持完整宽度，图库分类横向排列以保留首屏图片。
- 保留既有所有管理功能、接口、权限、保存后重启的区分及任务结果未知核对方式。
