# 2026-11-04 流式响应大小与内置插件空结果修复

任务13589在首次模型请求约192秒后以 `ai_response_too_large` 失败。任务回执中没有浏览器、采样、知识库或发送操作；持续浏览会话按失败规则停止。未自动恢复或重放旧任务。

此前 SSE 解析器对全部网络传输字节使用固定2 MiB上限，包含每个增量事件的协议封装和已丢弃的思考片段。这会让长推理或很多细小增量的正常响应过早失败。

现在分别限制：累计传输64 MiB、单个事件/未完整事件2 MiB、保留的正文和工具字段合计2 MiB。思考仍只记录存在标记，不进入后续模型上下文、聊天记录或日志。普通 JSON 响应仍保持2 MiB限制。请求时间、生成 Token 额度、推理与采样配置均不变。超限错误额外记录固定响应类型及字节计数，便于区分协议传输和实际输出超限。

另外，`douyin-web`、`video-analysis` 等仅提供工具的插件在普通消息分发中返回 `null`。原分发代码直接读取 `result.reply`，导致 `plugin_processing_failed`，提前跳出剩余插件。现在记录该插件执行后跳过空结果，继续后续插件和普通 AI 路由。

`emotion_appraisal_fallback` 表示可选情境理解没有产生可用结果，已回退本地规则；主回复仍可继续。这与视频任务的响应大小失败是不同路径，本次没有更改情绪插件设置。

回归模拟超过2 MiB的思考事件后继续调用工具、很多小正文事件、UTF-8字节预算、传输/单帧/工具参数上限及取消读取；并覆盖工具型内置插件之后的自定义插件与普通 AI 回复。使用当前 Qwen 配置进行一次只读工具调用验证，未执行浏览器动作或发送消息；不将该验证视为真实持续观看验收。
