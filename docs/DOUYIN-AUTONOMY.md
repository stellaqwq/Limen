# 指令刷视频、自动分享与私信

## 持续浏览和自主结束

不必每次指定条数。在已获授权的 QQ 管理员私聊或网页测试对话里：

- “去刷视频”“去抖音刷视频”：后台持续观看，直到收到“停止刷视频”“别刷了”或“停”。
- “去刷一会儿视频”“去抖音刷一阵”：模型根据实际画面决定继续看当前视频、划走或结束整个会话。用户同样可以随时喊停。
- “去刷3条视频”：仍按指定数量执行，受 `max_videos` 和任务时间约束。

持续/自主浏览无需开启自动分享。模型每轮采样一条当前视频，可以选择 `watch` 等待1–30秒后继续采样同一条，或选择 `next` 划走；自主模式另有 `stop`。采样不保证覆盖整条视频；开启[对白转写](DOUYIN-AUDIO.md)后会同时采集短音轨供理解和入库。每轮使用新的模型上下文，保留最近4次简短观看记录，并沿用发起会话的人格。轮次通过后台队列调度，普通聊天可以继续处理。

`max_videos` 继续约束指定条数的任务；持续浏览每轮处理一条，整个会话可以跨越多轮。`max_task_seconds`、Agent 模型请求及工具调用上限仍约束每一轮。持续会话会不断产生模型请求，直到停止。开启视频学习时，每轮决定前按既有规则归档。开启自动分享时，仅向原先绑定的默认好友分享，`browse_share_max_per_task` 按整个持续会话累计，达到限额后继续看、不再分享；持久去重规则不变。

“自主刷视频”中的“刷视频的模型思考强度”和“刷视频单次生成 Token 上限”只作用于观看分析、笔记和决定，普通聊天沿用原 AI 设置。默认留空和0表示沿用；本地模型连续观看过慢时，可使用 `none` 与2048做快速判断。保留思考时应预留足够的生成额度，额度包括思考与最终工具参数；服务需支持所选推理强度。画面数、采样间隔和音轨秒数不因此改变。

QQ 和网页停止指令在接收时直接取消会话和当前轮的后续操作，不等待模型回复。默认抖音好友的停止消息在轮次间按原检查间隔读取；这个入口仍需启用聊天读取与原有指令监听设置。管理页“停止网页操作”也会结束持续会话。正在提交的动作可能已生效，停止不会撤回已提交的分享。

失败、登录/验证阻挡、操作结果未知、权限/人格/插件配置变化、程序退出均结束会话。恢复控制或重启不会自行续刷，需要新的指令。后台轮次有会话授权与操作回执，失效轮次和旧启动指令不会恢复会话。状态保存在 `douyin_browse_sessions`，Agent 管理页显示模式、累计采样条数与分享数。

开启后，可以在 QQ 管理员私聊或已绑定的默认抖音好友会话里说：

> 去抖音刷5条视频，遇到你觉得有意思的就分享给我，再私信聊几句。

模型通过专用 Chrome 观察真实视频画面，自行判断是否有趣；有合适内容时，直接在抖音向已绑定的默认好友分享当前视频，再另发一条感想。可以一条都不分享。发送对象固定，QQ 发起者也不会成为新的抖音收件人。

## 设置

在“插件 → 抖音网页浏览 → 编辑”中配置：

- 启用插件及“分享与私信”，核对并绑定默认好友。
- 在“自主刷视频”打开“刷视频时自动分享给默认好友”（`browse_share_enabled`，新安装默认关闭）。保存即授权本流程自动分享和私信，无需逐条确认。
- `browse_share_max_per_task` 默认2，范围1–5。每任务浏览条数及时间仍受原来的 `max_videos`、`max_task_seconds` 约束。
- 指定观看5条、归档并分享时，建议预留24次模型请求和32次工具调用；本工作区已设置，任务与插件时间预算均为600秒。未指定条数时使用上面的持续/自主浏览模式。
- QQ 入口沿用 `qq_private_enabled`、聊天管理员、插件好友范围和 AI 白名单。群聊和普通用户没有自动推荐工具。
- 抖音入口需要 `web_enabled`、`chat_read_enabled`、已登录的专用浏览器、AI 与 Agent。普通 `chat_auto_enabled` 可以关闭；此时只响应明确的刷视频指令，不自动回复日常消息。

只询问“你能刷抖音吗”、否定指令和“只观看、不分享”不会获得自动推荐工具。使用直接指令“去刷视频”“去抖音看3条视频”等；含糊说法可改写为上述示例。

初次开启、保存配置、恢复控制和重启后，以当前消息为基线，只处理随后收到的新指令。抖音检查间隔与每小时任务限制沿用自动聊天设置；没有新指令时不调用模型。排队的抖音指令在配置修改、停止或重启后失效。

## 执行与记录

新增 `douyin_recommend_current` 组合工具：只接受本任务最近实际采样的 `observation_id` 和感想，不接受联系人、网址、选择器或脚本。执行层重新核对视频唯一 ID、登录账号和默认好友，分别创建并提交视频分享和私信，关闭社交面板后继续观看。没有稳定视频 ID 时不自动分享；开启自主分享且重新核对同一视频时，观察在本任务时限内有效（最多600秒），其余浏览动作仍为30秒。`douyin_web_action(close_social)` 只关闭没有未发送正文的面板，不覆盖手动输入。

明确的自主刷视频任务只提供浏览、知识库和推荐工具。执行层按状态查询、打开页面或关闭面板、真实采样、可选归档、内容决定、下一条的顺序要求调用工具，直到用户指定条数或配置上限。每条视频由模型通过 `decision=share/skip/stop` 决定分享、跳过或结束；跳过和结束不会发送。模型不能只在文字中说“已经分享”。最终回复由实际采样和提交记录生成，不转发模型未经核对的完成声明。

若工具执行后模型仅返回思考、没有完成必需调用，或模型服务返回流式格式错误，允许保留当前工具结果最多补试两次，不重跑已执行的动作；仍受总模型步数与任务时间限制。

每次自动推荐在 SQLite `douyin_recommendations` 记录视频、好友、任务及两份草稿的关联。同一视频按插件、登录账号、好友和视频 ID 持久去重；未知结果也不自动重发。进程中断留下的执行记录恢复为需核对，失败任务不以新操作编号重做。

返回 `submitted` 只说明分别激活过一次发送控件，不代表对方收到或已读；私信读取开启时额外检查当前会话可见发送记录。分享或私信调用结果未知、身份改变、视频变化、验证阻挡时停止，保留草稿供管理页核对。普通手动草稿仍走原来的准备与确认流程。

## 限制与验证

模型根据采样画面、可用的实际音轨转写和当前人格判断“有意思”，不能猜测配乐或未转写的对白。专用浏览器必须保持可用，登录和验证码由用户处理。

专项回归覆盖 QQ 权限与实际队列工具循环、视频分享加独立私信、跨任务及重启去重、发送结果未知停止、分享上限、视频变化、默认绑定、手动输入保护、配置撤销和抖音新指令触发。真实账号试跑记录与模拟测试分开保存，不以单元测试代表真实送达。
