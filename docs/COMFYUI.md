# ComfyUI 生图插件

在「插件 → 概览 → ComfyUI 生图」安装和配置。启用后模型获得 `comfyui_status` 和 `comfyui_generate`。QQ 需要同时符合插件好友/群范围、AI 白名单及人格工具权限；网页使用需开启「允许网页测试对话」。生成成功后图片经原有 QQ 发送队列发送，网页直接显示缓存图片。不会调用 QQ 向其他联系人发送测试图。

## 两种工作流模式

- 关闭「默认使用提供的工作流」：自动创建基础文生图流程。有 checkpoint 时选择配置的模型或首个已安装模型；没有 checkpoint 时尝试已安装的 Anima、Qwen3 0.6B 文本编码器和 Qwen Image VAE。
- 开启：粘贴 ComfyUI 导出的 **API 格式** JSON，或指定Limen主机上的 API 工作流文件路径。配置表单 JSON 最多 8000 字，较大工作流使用文件路径（最多 1 MiB）。普通画布 JSON 会提示重新导出 API 格式。

模型调用时可通过 `use_workflow: true/false` 单次覆盖默认模式。例如「用提供的工作流画一只白猫」或「不用提供的工作流，用基础流程画一座海边小屋」。

默认自动沿 KSampler 的 positive/negative 条件连接识别 CLIPTextEncode，替换提示词，随机化 seed；可选传入 `negative_prompt`、`seed`、`width`、`height`、`steps` 和 `cfg`。宽高应为 8 的倍数。提供的工作流中未指定的尺寸和采样参数保留原值。

自定义节点需要明确映射时，在「工作流参数节点映射」填写：

```json
{"prompt":["11.text"],"negative_prompt":["12.text"],"seed":["19.seed"],"width":["28.width"],"height":["28.height"],"steps":["19.steps"],"cfg":["19.cfg"]}
```

工作流需要 SaveImage 或 PreviewImage 输出节点。支持回复多张 PNG/JPEG/WebP 图片，单张缓存上限 4 MiB；优先回传正式输出，没有正式输出时回传预览。

## 批量生图与排队

模型在一次 `comfyui_generate` 调用中提交整批任务。相同提示词生成多张使用 `{"prompt":"一只白猫","count":3}`；不同提示词使用 `{"requests":[{"prompt":"白猫","count":2},{"prompt":"小狗","count":2}]}`。也可以说「分别画一只猫、一只狗，各两张」。根级尺寸、步数等参数作为各项默认值，每项可单独覆盖；根级 `prompt` 与 `requests` 二选一。

「批量与队列」默认每批最多 8 个生图任务、回传 8 张图，两项可分别配置为 1–16；实际允许展开的任务数取两者较小值。`count` 逐张提交工作流，提供 seed 时后续逐张递增；标准空潜空间节点的 batch_size 会设为 1。未传 count 或 count=1 时保留管理员工作流自身的 batch_size，输出超过回传上限的图片可在 ComfyUI 历史查看。CFG、步数和尺寸在模型未指定时保留原工作流配置。

所有对话共用串行队列，一批完成后处理下一批，默认最多 8 个等待中的对话，可配置为 1–32。网页显示排队位置、已完成任务数及全部缓存图片；QQ 回传该批全部图片，总大小超过单条消息限制时自动分条，已确认发送的部分不会重复发送。

单项明确失败时继续剩余任务；提交响应丢失或执行状态未知时停止后续提交，返回任务编号供核对。已完成的图片照常回传，不自动补交或重复生成。停用或修改插件会取消其正在等待的整批任务。重启后保留已缓存图片，但未提交的任务会取消，执行状态未知的任务不会重放。

## 生成图片进入会话上下文

开启 AI 的图片理解（`AI_VISION_ENABLED`，默认开启）后，生成图片会以 `image_url` 视觉输入直接加入当前会话；生图结束后再请求模型查看图片并回复。最多保留本批全部 16 张缩略图，每张最长边 768 像素，压缩为 JPEG；发给用户及网页下载的仍是原图。图片按回传顺序编号，同时标记所属任务。

图片随现有会话历史保存，后续可直接问「第二张是什么构图？」；重启后仍可引用，并遵守历史轮数限制和 `/new` 清空规则。图片不会注入其他会话。用于确认生图的写入记录仅保存任务和图片数量，不重复保存图片内容。

当前模型需支持视觉输入。关闭图片理解时保持直接返回图片；模型回看请求失败时仍回传已生成图片并说明未能回看，不重新生图。接口明确拒绝图片输入时移除本次历史中的视觉附件，避免影响后续文字聊天。

## 局域网连接

本机 ComfyUI：`D:\ComfyUI\start_comfyui.bat` 已加入 `--listen 0.0.0.0`。远程Limen插件地址使用 `http://192.168.1.2:8188`。修改 IP 后更新插件地址；两台机器需保持开机。ComfyUI 自身通常没有访问认证，不应对公网转发此端口。

单个工作流等待默认 600 秒，可调至 1800 秒；整批上限默认 1800 秒，可调至 7200 秒，包含排队、生成和下载。等待使用内置执行层，不受普通脚本 10 秒限制。插件停用或修改会终止等待；已提交的任务可能仍在 ComfyUI 执行，未发送全局中断。提交响应丢失、超时或重启均不会自动再次提交；按回复中的任务编号核对 ComfyUI 历史。

`DATA_DIR/comfyui-images` 存放下载图片，`comfyui_generations` 保存任务编号和缓存信息，随对应任务保留及清理。输出由 ComfyUI `/prompt`、`/history/{prompt_id}` 和 `/view` API 获取，参见 [ComfyUI 官方 API 定义](https://github.com/Comfy-Org/ComfyUI/blob/master/openapi.yaml)。

导出插件包：`runtime/desktop/node.exe scripts/comfyui-plugin.mjs`。首次更新内置执行层后需完整重启Limen；之后插件配置即时生效。
