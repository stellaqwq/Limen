## 不包含、不分发腾讯软件

本仓库的源码、文档与构建脚本中**不包含任何腾讯软件**：

- 没有 QQ 客户端程序文件，也没有 `wrapper.node`、`QQNT.dll` 等官方内核文件
- `runtime/`、`data/`、`dist/` 均被 `.gitignore` 排除，不随源码分发
- 首次启动时，程序读取 QQ 官方发版配置，由**使用者自己的机器**从 `qqdl.gtimg.cn` 下载安装包，校验腾讯 Authenticode 签名后解包使用。项目不代为分发，也不修改官方文件

**本项目明确禁止分发腾讯软件副本。** 包括把“含内核”的便携包（`Limen-Windows-x64-with-QQ.zip`，内含完整 QQNT 程序文件与 `wrapper.node`）上传到 GitHub Release、网盘、下载站或任何公开渠道。需要该形态请在自己的机器上用 `npm run desktop:build -- --qq-runtime=...` 现场构建自用，不要把产物发出去。对外分发只应发布源码包与不含 QQ 程序的便携版，让使用者首次启动时自行从官方渠道获取。

## 技术路径

程序不注入、不挂钩运行中的 QQ 进程，不修改官方程序文件，也不替换其协议栈；它把官方 QQ 程序文件复制成独立运行时，由本项目自研的 N-API 宿主加载官方 `wrapper.node` 已导出的接口，再把消息转换为 OneBot v11 事件与动作。账号数据保存在本机数据目录，由官方内核管理。

README 中标注为实验的 `native` 协议路线与本条主线无关，尚无真实账号验收，也不提供可用服务；它与 `kernel` 驱动不应混为一谈。

1. **账号风险**：通过非官方方式接入 QQ 可能违反《QQ 用户协议》，账号可能被限制、封禁或要求重新验证。建议使用小号，不要在主账号上运行。
2. **合法获取**：使用者须自行通过腾讯官方渠道获取 QQ 客户端，并遵守其许可条款。
3. **内容责任**：机器人发送的内容、调用的模型服务、采集的音视频与聊天记录，由使用者自行确保合法合规，并已取得相关方同意。
4. **数据外发**：截图、音轨、聊天上下文会发送到使用者自行配置的模型服务；调用前应关闭敏感页面，并自行评估该服务的数据处理条款。
5. **不用于规避风控**：本项目不提供绕过风控、批量注册、群发骚扰、自动化营销或规避平台限制的功能，也不应被改造用于这些目的。
