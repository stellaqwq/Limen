# Agent 的 3D 房间

本机房间项目：`D:\ai\Codex\2026-11-02\agent-room-demo`。

先启动房间，再重启 QQ 项目。在管理页的 Agent 网页试聊点击 **3D 房间**，新页面跟随当前试聊会话。原页面继续发消息即可，也能在房间输入框给同一个 Agent 发消息。这是网页试聊，不会把消息发送到真实 QQ。

收到任务时，角色侧躺拿起床上的手机；普通回复完成后放回；实际 trace 中出现命令、浏览器或电脑工具时，角色先放下手机，再坐在床边看桌上的电脑，结束后回到休息。网页试聊现有工具限制保持不变，此扩展没有增加命令执行或桌面控制权限。

房间端自动从本项目 `.env` 获取本机端口及 `ADMIN_ACCESS_TOKEN`。管理凭据只在两边服务端之间使用，前端不会接收它。新增只读接口均受管理鉴权保护：

- `GET /admin/agent/room?session=<网页试聊 UUID>`：当前会话的状态快照。
- `GET /admin/agent/room/stream?session=<网页试聊 UUID>`：状态 SSE，断连或关闭服务后清理定时器。

快照仅含所选 `web:<UUID>` 会话最近的任务状态、工具名与完成后的公开回复。不转发消息原文、工具参数、工具结果、私密推理或其他会话。判断电脑任务基于真实工具 trace，不能依靠用户在消息中提及“命令”来授予能力。

房间服务默认端口 4177。如需改用其他房间地址，可在房间页面的“联动其他 Agent”里选择 QQ，填写当前试聊 UUID；当前快捷入口固定指向本机 4177。点击“新会话”后，旧房间继续跟随原会话，请再次点“3D 房间”打开新会话。

完整接入说明、DeepSeek Harness 插件和通用事件协议见房间项目的 `AGENT-INTEGRATION.md`。
