# 安卓模拟器视频浏览

内置“安卓视频浏览”插件通过 ADB 固定连接一台设备，提供 `android_status`、`android_observe`、`android_action`。模型需要图片输入和工具调用能力；视频画面按时间采样为 JPEG，并非原生视频流。这个插件目前不采集手机声音，不能把已有的本地视频转写服务当作手机实时收音。

## 配置与使用

1. 启动安卓模拟器，在其设置中启用 ADB。使用模拟器管理器显示的端口连接，例如 `adb connect 127.0.0.1:16416`，通过 `adb devices` 确认设备已授权。端口随实例变化，不应猜测或自动选择其他设备。
2. 完整退出旧机器人并运行 `npm run launch`，进入“插件 → 插件概览 → 安卓视频浏览”。首次安装默认停用。
3. 填写 ADB 可执行文件路径、完整设备序列号、App 包名。默认包名为抖音 `com.ss.android.ugc.aweme`。项目复用已有 ADB 服务，不执行 `kill-server`，也不使用 root。

插件不自带 adb，必须使用电脑上已有的那份。路径可以留空，此时按下面顺序自动查找：

1. 配置项「ADB 可执行文件路径」里填的值（留空则跳过）
2. 系统 `PATH` 里的 `adb` / `adb.exe`
3. `ANDROID_SDK_ROOT` 或 `ANDROID_HOME` 下的 `platform-tools`
4. 常见安装位置：`%LOCALAPPDATA%\Android\Sdk`、MuMu 12（`shell\adb.exe`）、夜神 `Nox\bin`、BlueStacks `HD-Adb.exe`、雷电 `LDPlayer9`
5. 都没有时按裸命令 `adb` 执行，找不到会提示去填路径

`android_status` 会返回实际使用的 adb 路径与来源（`config` / `path` / `detected` / `missing`），排查时先看这一项。找不到 adb、设备未授权、设备离线、序列号填错会分别给出不同提示，并在序列号不匹配时列出 `adb devices` 当前连接了哪些设备。
4. 每任务默认最多 5 条、180 秒。保存后启用；仅允许已认证网页测试对话使用，QQ 群聊及私聊都不会获得手机工具。
5. 先在模拟器内完成首次协议、登录或权限提示，再从网页测试对话发送：“观看抖音，最多浏览 5 条，只观看和上滑，简短总结可见内容。”

“Agent 管理 → 安卓视频浏览”提供查看手机、停止、恢复和插件设置入口。截图按需获取，不自动刷新；手动查看与模型任务互斥，不会把手动截图混入正在执行的任务。只允许截图已配置的前台 App；其他 App 或系统窗口出现时停止观察，交给用户处理。

## 操作边界

- `android_action` 只接受 `open_app` 和 `next_video`，没有点击、输入、点赞、评论、关注、任意 shell 或 APK 安装接口。安装 App 由管理员在模型任务之外完成。
- 上滑必须引用同一任务最近 30 秒的观察编号；操作后编号作废。前台包名改变、设备离线、未授权、任务超时、超条数或正在被其他任务占用时拒绝输入。
- 第一条计入条数，默认最多四次上滑。`open_app` 每任务最多一次，不会重置计数。计数是浏览位置预算；一次上滑不保证一定切换了视频，模型应再次观察验证。弹窗、广告、直播和购物内容仍需模型从画面识别并停止，工具不能保证识别所有 App 内界面。
- 每个动作使用独立 `operation_id`，持久化回执防止相同动作重复执行。进程、模型请求或任务恢复时，执行过安卓动作的任务需要重新人工核对，不自动继续刷视频。
- 停止状态写入数据库，重启后保留；恢复只允许新任务。停止能取消尚未完成的 ADB 子进程，已经送达设备的动作可能生效。
- 手机截图只作为临时模型输入，不写入工具回执；独立验收命令会在 `runtime/android/phone.jpg` 保存一张本机截图。采样画面会发送给当前配置的模型服务，调用前应关闭敏感页面。

## 命令行

```powershell
npm run android:device -- configure --adb D:/Apps/pcsuite/adb_41/adb.exe --serial 127.0.0.1:16416
npm run android:device -- status
npm run android:device -- open
npm run android:device -- observe
```

`--adb` 可以省略，省略时按上面的顺序自动查找；adb 装在自定义目录（例如绿色版的应用宝目录）时仍需显式指定。`configure` 保存到 `runtime/android/device.json`，并为当前数据目录暂存一次性安装配置；下一次完整启动会安装、配置并启用新插件。已有插件保留原启用状态。其他数据目录的演示或测试实例不会误用该配置。日常修改建议直接通过管理页完成。

独立验收命令 `npm run android:device -- trial` 会真实调用当前模型，在单独的演示数据目录创建一个网页任务，最多浏览 5 条，只观察和上滑，不连接真实 QQ。结果在 `runtime/android/trial-result.json`。默认 Agent 最多 8 次模型请求可能不足以完成完整 5 条；独立验收允许最多 20 次，日常可以在执行设置中调整。

命令行 `stop` / `resume` 仅控制独立诊断数据库；正在运行的机器人任务请使用管理页的“停止安卓操作”。不要同时运行独立验收和机器人手机任务，以免争用同一设备。
