# 启动动画

打开工作台时，先播放一段自己设定的开场动画：可以用内置样式，也可以**上传本机视频当片头**。标记、标题、进度线和背景都在页面首帧就位，服务状态就绪后再收起。它由内置插件 `startup-animation` 提供，不处理聊天消息，也不需要 QQ 会话范围。

动画覆盖**整个启动过程**：桌面窗口一出现就播放，后台服务就绪后收起，再直接进入工作台；原先那张白色“Limen / 正在启动本机工作台…”占位页被完全替换，不会先闪一下白屏。工作台单独打开（浏览器或刷新）时，则由工作台首屏播放同一段动画。

## 开始使用

1. 更新源码后完全退出原服务并重新运行 `start.cmd`（或重新打开桌面版）；网页“重启生效”不会加载新的页面模板。
2. 打开左侧“插件”，进入“启动动画”，点击“安装启动动画插件”。安装后默认停用。
3. 点击“启用插件”。该插件不处理消息，因此无需填写好友或群聊范围。
4. 在右侧选择风格、底色，填写文案，拖动“最短展示时长”，左侧预览会跟着变化。
5. 点击“重新播放”可反复查看开场；点击“保存设置”后，**下次打开或刷新工作台**时生效。
6. 如需自己的标记，点击“选择图片”上传 Logo；没有上传时使用内置的对话气泡标记。
7. 想用视频当片头：在“自定义启动视频”点击“选择视频”，挑一个 MP4 或 WebM 文件（≤ 40 MiB）。上传后**自动切换到「我的视频」并立即保存**，无需再点保存；预览里会同步播放。点“移除”会回到内置动画。

## 显示参数

| 参数 | 配置键 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 显示启动动画 | `enabled` | 开 / 关 | 开 | 插件启用时的总开关；关闭后页面直接进入 |
| 动画来源 | `source` | `preset` / `video` | `preset` | 内置动画或已上传的视频片头；没有视频时自动回退到内置动画 |
| 视频填充 | `video_fit` | `cover` / `contain` | `cover` | 铺满窗口（裁切边缘）或完整显示（留白用底色补齐） |
| 视频循环播放 | `video_loop` | 开 / 关 | 开 | 短片循环到工作台就绪；关闭后播完停在最后一帧，不会忽然变黑 |
| 视频上叠加标题文案 | `video_overlay` | 开 / 关 | 开 | 关闭后只显示视频，适合自带片头文字的素材 |
| 动画风格 | `preset` | `orbit` / `pulse` / `stars` / `curtain` | `orbit` | 轨道、涟漪、星屑、幕启 |
| 底色 | `theme` | `ink` / `paper` / `aurora` | `ink` | 墨黑、纸白、极光 |
| 强调色 | `accent` | `#rrggbb` | `#8b7cf6` | 光环、进度线、光晕和幕布后的光 |
| 主标题 | `title` | 最多 24 字 | `Limen` | 留空则不显示 |
| 副标题 | `subtitle` | 最多 60 字 | `你的机器人，由你掌控` | 留空则不显示 |
| 启动提示 | `caption` | 最多 40 字 | `正在启动本机工作台` | 显示在进度线下方 |
| 最短展示时长 | `min_ms` | 600–8000 毫秒 | 1800 | 状态就绪后仍保留这段时间；进度线按它填满 |
| 退出方式 | `exit` | `fade` / `rise` / `zoom` | `fade` | 淡出、上升、推近 |
| 显示进度线 | `show_progress` | 开 / 关 | 开 | 进度线按最短展示时长从左向右填满 |
| 点击任意处跳过 | `skippable` | 开 / 关 | 开 | 点击、回车、空格或 Esc 立即收起 |
| 每次会话只播放一次 | `once_per_session` | 开 / 关 | 关 | 同一浏览器会话刷新页面不再播放；改动样式后签名变化，会重新播放 |

四种风格：

- **轨道**：三层光环以不同速度旋转，光点沿环移动，标记带轻微扫光。
- **涟漪**：从标记向外扩散三圈涟漪，适合更安静的开场。
- **星屑**：两层星点在背景缓慢漂移，适合深色或极光底色。
- **幕启**：两块幕布向两侧打开，露出中心；幕布后有一团强调色光晕。

三种底色都跟随“强调色”变化；纸白底色会自动降低光晕强度，保证文字对比度。

## 视频片头与过渡

上传视频后，桌面启动窗口与工作台首屏都会改播这段片头；视频静音、内联、按需循环，不占用音频设备。

- **格式**：MP4（`ftyp` 容器，建议 H.264 + `+faststart`）或 WebM（EBML 容器）。文件按内容嗅探，改扩展名、伪装的图片或 SVG 会被拒绝；单个不超过 **40 MiB**。MOV / AVI / MKV 不在支持范围内，浏览器不一定能解码。
- **上传方式**：`选择视频` 走独立的二进制上传接口，不转成 base64，也不会挤占 Logo 的 2 MiB 请求上限；媒体与文案都留在本机，CSP 只允许 `media-src 'self'`。视频与 Logo 各自独立，切换来源不会删除文件。
- **入场不黑闪**：首屏先画内置动画（同主题底色、光环、标题），`<video>` 初始透明；等 Chromium 真正解码出第一帧并成功播放，才用约 700 毫秒把视频交叉淡入、把装饰层同步淡出。视频加载失败、6 秒仍无画面或浏览器拒绝自动播放时，直接回到内置动画，**不会卡住启动**。
- **退出不硬切**：收起时视频先轻微推近、模糊、压暗，同主题色的幕布同时渐显；整层再淡出并被移除。工作台单独打开（浏览器刷新）时也是同一段过渡。
- **交接不重播**：桌面窗口已经播过视频，跳到 `?boot=1` 的工作台时，交接帧**不再创建 `<video>`**，只保留同色遮罩再溶解到管理台；因此不会看到片头播第二遍、也不会出现黑场。
- **播完不黑屏**：关闭“循环播放”时视频停在最后一帧，直到状态就绪后按上面的过渡收起；视频比最短展示时长长也不会被强行截断。
- **预览一致**：管理页左侧预览使用同源视频地址，同样等有画面后淡入；点“重新播放”会重新走一遍过渡。切换回“内置动画”时预览里的视频会暂停并移除。

## 播放时机与兜底

- 桌面版：插件把已保存的外观同步到数据目录的 `boot.json`。Electron 主进程在启动后台前读它，用临时本机页面渲染同一套动画和 Logo，等满设置的“最短展示时长”后冻结并快速淡出，再跳转到带 `?boot=1` 的工作台。
- 交接是连续的：工作台那一页先垫上**同主题的背景**（不再重复 Logo 与标题，避免看起来像又播了一遍），后台状态到达后这层遮罩在约半秒内溶解，露出已经渲染好的工作台；期间隐藏滚动条并预留位置、背景色跟随主题，避免过渡时出现跳动、白边或白闪。
- 桌面窗口立刻显示（隐藏的窗口会暂停入场动画，反而只剩一块空背景），启动页的首帧就带上完整的 Logo、标题与光环：装饰动画照常运动，入场淡入直接跳过，因此不会出现“纯黑一下再出动画”。
- 交接遮罩不会“卡住”：它由主进程、工作台脚本两路同时释放（页面自身还有 1.5 秒兜底），并且是半透明的——即使极端情况下没被释放，工作台也只是被压暗，不会变成一块黑屏。
- **改完源码要完全退出应用再重新打开**：Electron 不会热更新，已经开着的窗口仍在跑旧代码。
- 窗口背景色与动画底色一致，即使页面还没画完，露出的也是动画本身的底色而不是另一种颜色。
- 工作台：页面 HTML 由服务端按当前设置渲染，覆盖层在第一帧就存在，不会先闪一下管理台再盖上去。
- 工作台首个 `/state` 返回后调用退出；若后台迟迟没有响应，覆盖层最长 **12 秒**后自动收起，避免挡住管理台。`?boot=1` 的那次导航会跳过覆盖层，刷新页面仍会正常播放。
- 开启“点击任意处跳过”时，覆盖层接收指针抬起和键盘事件；跳过也会写入“每次会话只播放一次”的标记。
- 系统开启“减少动态效果”时，CSS 动画被禁用，覆盖层仍按时间收起，不会卡住页面。
- 覆盖层不包含可聚焦元素，`aria-hidden` 标记为装饰，不影响键盘用户进入工作台。
- 视频模式下退出过渡约 720 毫秒，之后才移除节点；12 秒兜底与点击跳过仍然有效，遮罩不会长时间挡住管理台。

## 存储与边界

- Logo 保存在数据目录的 `startup-animation/` 下：`logo.<png|jpg|webp|gif>` 与记录格式、尺寸和 SHA-256 的 `state.json`；另有一份 `boot.json` 快照供桌面启动窗口读取。
- 每次上传替换旧文件，`remove-logo` 清理图片与 `state.json`（保留 `boot.json`），删除插件会连快照一起清空。安装、启停、保存、上传和删除都会同步刷新快照。
- 视频保存在同一目录的 `video.<mp4|webm>` 与 `video.json`（格式、大小、SHA-256、文件名）；`remove-video` 会删除这两个文件并把动画来源切回内置样式，删除插件则把所有媒体与快照一起清空。
- 每次上传替换旧文件：旧格式与新格式不同时先写新文件再清理旧的，不会残留两份片头。
- 读取图片和视频时都重新校验 SHA-256，文件被替换或损坏会返回 409 并提示重新上传。
- 接受 PNG、JPEG、WebP 与 GIF（Logo ≤ 2 MiB），以及 MP4 / WebM（视频 ≤ 40 MiB）；GIF 会循环播放，适合动态标记。SVG 与容器头不匹配的文件会被拒绝，避免脚本注入。
- 文案在保存前去除控制字符并限制长度，渲染时统一转义；强调色只接受 `#rrggbb`，枚举与开关都由配置 schema 校验。
- 页面通过同源代理读取 Logo 与视频，CSP 为 `img-src 'self' data:` 加 `media-src 'self'`；页面本身不含管理员 Token。管理端与桌面临时服务都支持 `Range` 请求（206），MP4 可以正常拖动与预读。

## 接口

与其他内置插件一致，接口只接受管理员 Token：

| 接口 | 参数 / 结果 |
| --- | --- |
| `GET /admin/startup-animation` | 返回插件记录、Logo 与视频元数据、当前参数、`signature` 和大小上限 |
| `POST /admin/startup-animation/action` | `{action:"upload-logo",data:"data:image/png;base64,…"}`、`{action:"remove-logo"}`、`{action:"remove-video"}`、`{action:"save",source,video_fit,video_loop,video_overlay,preset,theme,accent,title,subtitle,caption,min_ms,exit,show_progress,skippable,once_per_session,enabled}` |
| `POST /admin/startup-animation/video` | **原始字节**上传（`Content-Type: video/mp4` 或 `video/webm`，`X-File-Name` 可为 URL 编码的文件名），校验容器头后保存，并自动把 `source` 切到 `video` |
| `GET /admin/startup-animation/media` | 返回 Logo 字节，附带 `Content-Type` 与 `Content-Length` |
| `GET /admin/startup-animation/video` | 返回视频字节，支持 `Range`（206 / 416）与 `Accept-Ranges` |
| `GET /admin/status` | `startup` 字段供工作台首屏直接渲染 |

工作台侧边代理为 `/startup-animation`、`/startup-animation/action`、`/startup-animation/media`、`/startup-animation/video`；写入同样要求同源 `Origin`，视频上传请求上限 42 MiB。代理会把快照里的 Logo 和视频地址都改写成带随机登录前缀的同源路径，首屏 `<img>` / `<video>` 与管理页预览才能在当前页面加载。页面在每次加载时读取 `/admin/status` 的 `startup` 字段，带 1.2 秒超时：后台正在重启或版本较旧时退回不带动画的页面，不阻塞打开。

## 换机器与分发

插件包只依赖自己的目录与 `plugins/_host`，不含绝对路径、不 import `src/`、不需要第三方 npm 包；Logo 路径在运行时取自数据目录。

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 插件代码 | `plugins/startup-animation/` | `plugin.json`、`index.mjs`、`config.mjs`、`service.mjs`、`management.mjs` |
| 宿主支持 | `src/onebot.mjs`、`src/plugins/{registry,service}.mjs`、`src/web/{startup-animation,page,client,plugin-hub,login-server}.mjs`、`desktop/main.mjs` | 接口、首屏渲染、桌面启动页与面板由宿主提供，旧构建没有这些文件；视频还需要管理员/工作台/桌面的 `/video` 路由与 `media-src` CSP |
| 已上传的 Logo、视频与快照 | `DATA_DIR/startup-animation/` | `logo.*`、`state.json`、`video.*`、`video.json`、`boot.json` 不随插件包走；只有迁移数据目录时才会带过去 |
| 插件记录与参数 | `DATA_DIR/bot.sqlite` | 换机器需要重新安装并启用；参数不迁移则使用默认值 |

打包 zip 时路径必须使用 `/`：Windows 的 `Compress-Archive` 会写成 `startup-animation\config.mjs`，被宿主以“包含无效路径”拒绝。用 7-Zip 或 `tar -a -c -f startup-animation.zip startup-animation` 生成的包可以正常安装。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 打开“启动动画”提示插件包未安装 | `plugins/startup-animation` 未随包分发或被删除，重新放回目录后重启服务 |
| 保存后打开工作台没有动画 | 确认插件已启用、配置里“显示启动动画”已打开；浏览器会话里曾播放且开启了“只播放一次”时，换一个标签页或清除站点数据 |
| 桌面版仍显示白色“正在启动本机工作台…” | 确认插件已启用并重启应用；`DATA_DIR/startup-animation/boot.json` 不存在或 `enabled:false` 时会退回原生占位页 |
| 动画结束到工作台出现有跳变 | 交接帧由工作台同页渲染，若仍看到跳变请检查是否使用了较旧的构建（工作台需支持 `?boot=1` 交接帧） |
| 动画一闪就消失 | 提高“最短展示时长”；状态就绪很快时，动画仍会保留这段时间 |
| 动画挡住页面很久 | 检查服务是否正常；最长 12 秒会自动收起，也可开启“点击任意处跳过” |
| 上传提示图片无效 | 确认是 PNG/JPEG/WebP/GIF 且小于 2 MiB；SVG 与改扩展名的文件会被拒绝 |
| 上传视频后仍播放内置动画 | 确认上传成功且“动画来源”是「我的视频」；视频文件损坏时会自动回退，重新上传一次 |
| 视频提示内容无效或超过大小 | 只接受 MP4 / WebM 且 ≤ 40 MiB；MOV、AVI、MKV 请先转成 H.264 MP4（`ffmpeg -i in.mov -c:v libx264 -pix_fmt yuv420p -movflags +faststart out.mp4`） |
| 视频有声音但听不到 | 启动视频一律静音，这是浏览器允许自动播放的前提；有声素材不会播放音轨 |
| 视频开头黑一下或播两遍 | 检查是否用了旧构建：新版本在视频解码出第一帧后才淡入，桌面交接帧不创建 `<video>`；改完源码要完全退出应用再打开 |
| 文字看不清 | 纸白底色适合深色文案；深色图片 Logo 建议配极光或墨黑底色，或换一个对比更强的 Logo；视频上可关闭“叠加标题文案” |
