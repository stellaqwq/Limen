# 非流式平台实时分段回复

「全部设置 → AI 与回复 → 非流式平台实时分段回复」控制 QQ 的回复发送方式。对应 `AI_SEGMENTED_REPLY_ENABLED`，默认开启。

- 开启：收到模型输出的完整句子就发送一条消息，长句按「流式分段长度」拆分。最后剩余正文通过原有发送队列发送，不重复已经发送的内容。
- 关闭：QQ 等到完整正文生成后发送，网页仍按「模型流式输出」实时显示。

需要同时开启「模型流式输出」（`AI_STREAM_ENABLED`）。模型接口也需要支持流式返回；如果它只返回完整 JSON，程序只能在完整响应到达后发送，无法在服务端尚未返回内容时提前分段。

分段仍遵守消息限流、引用、群聊 @、Emoji 过滤和插件的语音或纯图片缓冲规则。生成中断后不重放已经发送的消息；送达结果未知时停止并保留核对记录。只发送正文，不把模型思考内容发到 QQ。

保存配置后重启生效。该开关只控制聊天渠道的发送方式，网页的原生流式展示独立处理。
