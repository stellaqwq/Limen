# 记忆总结继承角色设定

流动记忆 1.1.0 的后台自动总结和 `/lmem summarize` 都使用主 AI 的系统提示词（默认角色）。若当前 QQ 会话绑定了 Agent 人格，则追加这个会话的人格提示词。没有绑定人格时使用系统提示词；不会读取其他会话或其他用户的人格。

总结仍使用插件中配置的总结模型；留空时沿用主模型。请求只携带当前用户、会话、人格的待整理对话，不使用聊天工具。角色设定帮助理解称呼、关系和指代，不直接作为新记忆写入；记忆来源、凭据过滤和 JSON 提取规则继续生效，且只保留一份整理规则。

当总结期间系统提示词、人格提示词或人格版本发生变化时，旧结果不写入，待整理原文保留，供后续按新设定总结。已有长期记忆不会因此重写或清空。
